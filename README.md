# R01 — The Character Atelier

Original, procedural Blender character study and responsive web inspection app.

**Author / environment:** GPT-6 Astra Pro · mcp_colabdev · Blender headless.

This is a work in progress, not an exact likeness or a completed AAA-quality character. The live journal records actual reviewed iterations, including visible defects. The requested 20,000 iterations and >95/100 target have not been completed or verified.

## What is original

All character meshes, hair curves, clothing surfaces, shoes, hands, backpack components, and texture maps are generated by `src/build_character.py`. No downloaded model, scan, image-to-mesh result, purchased character, existing local character asset, or source-photo texture is used. The supplied PNG is retained only as a visual reference and an optional side-by-side comparison in the app.

Blender, Three.js, Playwright, esbuild, and glTF Transform are software dependencies, not character assets. The reference is user-supplied; no ownership claim is made over that photograph.

## Generate the character

Use Blender 4.2.3 LTS with Cycles and OpenImageDenoise. The official binary is installed at `/home/dev/.local/opt/blender-4.2.3-linux-x64/blender` in the current Colab instance.

```bash
npm ci
REVISION=5 SAMPLES=96 RENDER_HEIGHT=1440 \
  src/blender_official.sh -b -t 8 --python src/build_character.py
src/compress.sh
VIEWS=threequarter,side,back,face SAMPLES=96 \
  src/blender_official.sh -b \
  build/preview/gpt6_astra_pro_mcpcolabdev_blender_rgirljk.blend \
  -t 8 --python src/render_views.py
npm run bundle
cp web/index.html web/style.css build/
python3 src/serve.py
```

On another machine, replace `src/blender_official.sh` with the local Blender executable. Do not execute the archived refinement/patch scripts against the already-refined generator.

The distro Blender 4.0.2 fallback needs relocated script/data paths and does not include a usable denoiser. The official build is preferred. The failed environment attempts are retained in `logs` in the live workspace, not in the published static site.

## Review, do not manufacture scores

Inspect actual rendered files visually. Then record a completed build-and-review with:

```bash
python3 src/review.py 5 72 'Meaningful title' 'Honest observed improvements and remaining defects.'
```

The numbers above are examples of command syntax, not an instruction to award that score. Do not count samples, frames, random parameter changes, loop steps, or QA assertions as thousands of completed visual iterations. The score is subjective and not an objective image-similarity measurement.

## Web preview

```bash
npm run preview
# http://127.0.0.1:8794
```

The app has orbit/zoom controls, front/three-quarter/side/back/face presets, optional turntable rotation, a reference comparison, studio renders, direct asset downloads, explicit absolute file paths, and a live revision journal. It polls `status.json` every eight seconds without reloading the page or resetting the user's camera.

All runtime viewer code is bundled locally. Meshopt decoding is included; the page does not need a CDN, model service, or external image library.

## Validation and outputs

`src/browser_test.mjs` exercises a 1440px desktop and 390px mobile viewport, checks horizontal overflow and JavaScript errors, tests the back-view and reference buttons, and writes screenshots plus `build/browser-audit.json`.

`build/geometry-audit.json` records mesh budgets and the solved hip/knee/ankle locations. Both thighs use 0.438 m and both shins use 0.398 m; different screen-space leg lengths are possible because of the pose and perspective. These lengths are modeling choices, not measurements of the person in the reference.

Important outputs live in `build/preview/`: the editable `.blend`, web `.glb`, and current render views. Reviewed front-view milestones live in `build/reviews/`. Old `.blend1` backups and temporary GLBs should not remain in the published preview directory.

## Interpretation limits

Only one reference view is available. The back of the backpack, hands behind the body, rear hair, and unseen garment surfaces are authored interpretations. The character is a static posed model, not a production animation rig. Facial likeness, material realism, topology, and all-side naturalness require further review.

See `Agents.md` for the current state, actual reviewed iteration count, outstanding issues, process IDs and exact continuation instructions.
